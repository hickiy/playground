# Three.js 3D 渲染练习场

一个独立的 Three.js 入门练习项目。页面中的几何体、灯光、相机和控制项都在 `src/main.js` 中创建，适合边运行边阅读。

## 运行

需要 Node.js 20.19+（或 22.12+）和 pnpm：

```bash
pnpm install
pnpm dev
```

按终端提示打开本地地址。生产构建：

```bash
pnpm build
pnpm preview
```

## 页面练习

- **旋转视角**：拖动场景或滚轮缩放，理解 OrbitControls 操作的是相机视角。
- **点击几何体**：通过 `Raycaster` 从屏幕坐标发射射线，找出与场景相交的物体。
- **调整世界坐标**：拖动 X/Y/Z 滑块，观察模型位置变化。
- **切换相机投影**：对比透视相机与正交相机。透视投影会产生近大远小，正交投影保留物体屏幕尺寸。
- **切换坐标轴、网格、线框和自动旋转**：对应 Three.js 中的辅助对象、材质和控制器属性。
- **重置场景**：还原物体位置、相机、投影和显示选项。

## 阅读顺序

打开 `src/main.js`，依次阅读：

1. `WebGLRenderer`、`Scene` 和相机初始化
2. 灯光、地面、网格和坐标轴
3. `createObject`：几何体、材质、网格对象和位置
4. `OrbitControls` 与相机投影切换
5. `Raycaster` 拾取和位置滑块
6. `resizeRenderer` 与渲染循环

## 渲染概念

渲染可粗略理解为将模型顶点依次变换到世界坐标、相机坐标，再通过投影映射到屏幕，最后结合光照与材质得到像素颜色。Three.js 帮你处理大部分矩阵和 GPU 工作；这个练习的重点是改变一个输入，观察最终画面如何变化。

本练习使用程序生成的几何体，不需要额外模型文件或在线资源。
